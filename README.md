# 대동맛지도

## 무엇을 하는 서비스인가

여행하며 현재 위치하고 있는 지역의 지도상에서 맛집을 골라 찾아갈 수 있는 서비스.

지금 쓸 수 있는 기능은 아래와 같습니다.

- 가게 이름으로 검색하면 네이버 별점과 카카오 별점을 하나로 합친 **통합 점수**를 보여 줍니다.
- 검색 결과에는 **지금 영업 중인 가게**만 통합 점수가 높은 순서로 최대 10곳까지 세로 목록으로 나옵니다.
- 카카오에서도 같은 이름으로 찾아, 카카오에서만 나온 가게는 이름과 주소를 따로 보여 줍니다. 이 가게들은 별점과 영업시간 정보가 없어 "통합 점수 없음" 으로 나옵니다.

## 누구를 위한 것인가

지역을 방문하는 여행객을 위한 서비스입니다.

- 혼자 또는 친구와 함께 국내 소도시로 1~2박 여행을 다니는 사람
- 여행 전 목적지를 정하지 못하고, 돌아다니다가 갑자기 맛집을 정해야 할 때
- 핸드폰 화면 하나로 여러 사이트를 검색하고 비교하기에 번거롭고 시간이 없을 때

## 어떻게 쓰나

1. 첫 화면에서 **「시작하기」** 를 누릅니다.
2. **가게 이름** 칸에 찾고 싶은 가게 이름을 넣고 **「검색」** 을 누릅니다. 입력 칸에서 엔터를 쳐도 됩니다.
   - 입력을 비워 두고 검색하면 "가게 이름을 입력해 주세요" 라고 안내합니다.
   - 없는 가게 이름이면 "'○○'라는 가게를 찾지 못했어요. 이름을 다시 확인해 주세요" 라고 안내합니다.
3. **검색 결과** 화면에서 영업 중인 가게와 통합 점수를 확인합니다.
4. 다른 가게를 찾으려면 **「다시 검색하기」** 를 누릅니다. 검색 결과 화면 위쪽 가게 이름 칸에 바로 새 이름을 넣고 「검색」 을 눌러도 됩니다.
5. 첫 화면으로 돌아가려면 왼쪽 사이드바의 **「첫 화면으로 돌아가기」** 를 누릅니다.

그 밖에 누를 수 있는 것

- **「AI 지역 추천」 탭** : 지금 있는 지역 이름을 넣고 **「내 지역 가게 보기」** 를 누르면 AI 가 그 시각에 문을 열었을 음식점을 적어 줍니다. AI 가 알고 있는 내용으로 만든 목록이라 실제 영업 여부와 다를 수 있습니다.
- **오른쪽 아래 🐣 버튼** : 누르면 챗봇 창이 열립니다. **말투** 를 고른 뒤 서비스에 대해 궁금한 것을 물어볼 수 있습니다.
