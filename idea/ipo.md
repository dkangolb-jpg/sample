# 넣으면 나온다

한 줄 : 가게 이름을 넣으면 → 지금 영업 중인 가게들의 이름과 통합 점수 목록이 나온다

- 입력 : 사용자가 방금 본 가게 이름을 넣는다
- 처리 : 네이버 별점과 카카오 별점을 하나의 점수로 합쳐서 계산한다
- 출력 : 지금 영업 중인 가게들의 이름 + 통합 점수가 세로 리스트로 여러 개(예: 5~10개) 나열된다
- 모양 : 모아 보여주는 화면


- 잘못 넣었을 때 : 입력을 비워 두면 "가게 이름을 입력해 주세요"라고 보여준다
- 잘못 넣었을 때 : 오타 등으로 없는 가게 이름이면 "'○○'라는 가게를 찾지 못했어요. 이름을 다시 확인해 주세요"라고 보여준다
